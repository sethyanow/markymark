## Checklists — Overview

Extractable checklists for code review, auditing, and release validation.
Each checklist uses GitHub-flavored task lists and can be copied into PRs.

### Files

| File | Purpose | When to Use |
|------|---------|-------------|
| [api-design.md](api-design.md) | Public API review | Designing or reviewing library APIs |
| [unsafe-review.md](unsafe-review.md) | Unsafe code audit | Reviewing unsafe blocks |
| [ffi-audit.md](ffi-audit.md) | FFI boundary check | Adding or reviewing FFI code |
| [performance.md](performance.md) | Performance review | Optimizing or reviewing hot paths |
| [library-release.md](library-release.md) | Library publishing | Before `cargo publish` |
