## CRITICAL GAPS (zero coverage in rustdocs, substantial in gigapowers)

### 1. `impl Trait` / RPIT / APIT

**Current state:** Zero dedicated headings in rustdocs.
**Gigapowers source:** `reference/types/impl-trait.md` (14 headings), `book/ch10-02-traits.md`, `rust-by-example/trait/impl_trait.md`
**Where to add:** `core/traits.md` — new section covering:

- Limitations: can't name the type, can't use in trait definitions (before RPITIT)
- RPITIT (Rust 1.75+): `async fn` in traits without `#[async_trait]`
- Decision: `impl Trait` vs `dyn Trait` vs generic parameter

### 3. `no_std` / `#![no_main]`

**Current state:** Zero content in rustdocs.
**Gigapowers source:** `nomicon/beneath-std.md` (12 headings), `nomicon/panic-handler.md` (17 headings)
**Where to add:** New section in `tooling/cargo.md` or `advanced/` covering:

### 4. Rust 2024 Edition Changes

**Current state:** Not documented at all.
**Verified:** Stabilized in Rust 1.85.0 (February 2025).
**Where to add:** New `reference/edition-2024.md` covering key changes:

| Category | Change | Impact |
|----------|--------|--------|
| Language | `gen` keyword reserved | Cannot use as identifier |
| Language | `unsafe extern` blocks required | All FFI code must update |
| Language | Never type (`!`) fallback changes | Type inference edge cases |
| Language | Match ergonomics restrictions | Pattern matching behavior |
| Stdlib | `Future` + `IntoFuture` in prelude | May cause name collisions |
| Stdlib | `IntoIterator` for `Box<[T]>` | New iteration capability |
| Stdlib | `set_var`/`remove_var` now unsafe | Test fixtures must update |
| Async | `async \|\|` closures supported | New async pattern |
| Cargo | Rust-version-aware dependency resolution | MSRV enforcement |
| Cargo | Consistent kebab-case in Cargo.toml | Config key naming |

### 10. tree-sitter `Node: !Send + !Sync`

**Current state:** Not documented in tree-sitter.md.
**Verified:** `Parser` is `Send + Sync` (via unsafe impl), but `Node` is `!Send + !Sync` (contains raw `*const TSTree` pointer).
**Impact:** Directly affects async LSP code — holding a `Node` across `.await` is a compile error.
**Where to add:** `rust_crates/tree-sitter.md` — new Thread Safety section.

### 13. LazyLock (std::sync::LazyLock)

**Current state:** Not mentioned anywhere in rustdocs.
**Verified:** Stabilized in Rust 1.80. Replaces `lazy_static!` and `once_cell::sync::Lazy`.
**Nuances:** Unrecoverable poisoning (if init panics, all future accesses panic). `LazyLock::get()` stabilized in 1.94.
**Action:** Add to `tooling/crates.md` as recommended replacement.

## PROCESS NOTE: Markymark as Surgical Content Extractor

For future sessions, use this workflow to reduce token cost:
1. `create-realm` + `add-root` for both doc sets
2. `search-symbols` to identify exact heading locations
3. `export-index` or `get-outline` to get line ranges for specific headings
4. Dispatch haiku subagents with XML-wrapped surgical prompts targeting exact line ranges
5. Haiku agents extract and summarize content, relay back to orchestrator

Example prompt for haiku agent:
```xml
<task>
  <source>gigapowers/.rust_docs/reference/items/associated-items.md</source>
  <lines>252-396</lines>
  <instruction>Extract the GAT explanation. Summarize in 20 lines max as an agent-friendly
  reference with: definition, syntax, required where clauses, and one practical example.</instruction>
</task>
```

This avoids opus agents reading full 600-line files when only 50 lines are relevant.
